# Geospatial Project Collection

| Project | Workflow |
|---|---|
| [Automated Sentinel-2 Time Series](sentinel2-timeseries/) | Monthly indices, observation counts, coverage QA and COG exports. |
| [Nepal Land-Use Mapping and Vector QA](nepal-landuse/) | Geometry/attribute validation, duplicates, overlaps, coverage gaps and issue reports. |
| [Vegetation Change](vegetation-change/) | Cloud-masked NDVI/SAVI/EVI comparisons and raster exports. |
| [Sentinel-2 Random Forest Classification](random-forest-landcover/) | Pixel cloud masking, spatial group holdouts and accuracy outputs. |
| [Sentinel-1 SAR Change](sentinel1-sar-change/) | Matched relative orbits, dB differences and new-water candidate screening. |
| [Raster ETL and QA/QC](geospatial-raster-etl-qaqc/) | Windowed real-file inspection, metadata checks, mosaicking and clipping. |
| [Spatial Validation Benchmark](spatial-validation-benchmark/) | Random versus disjoint-block evaluation with saved predictions and group IDs. |
| [Terrain and Hydrology](terrain-hydrology-modeling/) | Slope with metre spacing, D8 routing and contributing-area checks. |
| [Environmental Monitoring Methods](south-florida-environmental-monitoring-geoai/) | Index/change/SAR utilities with a runnable raster demonstration. |
| [Flowering and Season Yield Estimation](dragon-fruit-yield-flowering-forecasting/) | Plant-grouped models, contemporaneous flowering status and end-of-season yield estimates. |

Run Python commands from the chosen project folder. Earth Engine scripts require configured inputs and a live Earth Engine run. Each README identifies the data pathway and output interpretation.
