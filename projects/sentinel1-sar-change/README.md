# Sentinel-1 SAR Change Detection

**Proposed historical period:** 2025 (verify). **Code published:** 2026.

Earth Engine example compares median pre/post-event Sentinel-1 VV backscatter and shows difference in dB. Supply an appropriate AOI, dates and external reference observations for validation. The Earth Engine GRD collection is already calibrated and terrain-corrected; this example does not implement a separate ESA SNAP terrain-correction workflow or explicit speckle filter. Do not claim validated flood or vegetation-loss results from this example alone.
