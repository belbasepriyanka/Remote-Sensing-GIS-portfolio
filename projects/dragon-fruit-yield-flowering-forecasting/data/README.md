# Data

The committed `sample_dragon_fruit_yield_preview.csv` is a small public preview. Running `python scripts/run_demo.py` generates the full synthetic dataset with 72 plants × 8 repeated observations = 576 rows.

The schema includes plant ID, environment, species, amendment treatment, weather, growth, NDVI/NDRE, soil/tissue variables, flowering, fruit set, and synthetic yield. Values are demonstration data only, not unpublished research measurements.
