# Random Forest Land-Cover Classification

**Proposed historical period:** 2024 (verify). **Example code published:** 2026.

Sentinel-2 GEE demonstration using labeled reference points. Supply a feature collection named `training` with a numeric `class` property, a valid study-area polygon, and independent validation points. Class count, overall accuracy and kappa are deliberately not stated until actual data are processed. Avoid evaluating on training samples alone.
