# National Land-Use Classification, Nepal

**Historical project period:** 2018–2022 according to resume; **documentation published:** 2026. Do not describe this as a 2023 project without confirming continued work.

Resume-described work: satellite-image land-use classification and suitability analysis spanning 15+ municipal districts, and enterprise geodatabases with topology rules, domains and subtypes. Original project geodata and ArcGIS geodatabase are not included.

`check_geometries.py` is a new, general-purpose QA demonstration, not the original national-project source code. Usage: `python check_geometries.py input.geojson`.
