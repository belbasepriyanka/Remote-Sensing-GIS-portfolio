## Getting started

Open a project README and run commands from that project folder. Python projects provide requirements, sample inputs, generated outputs and tests. Earth Engine workflows require an authorized Earth Engine project, configured boundaries/dates and an interactive run.

[Verification report](docs/verification.md) lists checked workflows and execution boundaries. [Project index](projects/README.md) links to every folder.

## Research context

I am an Earth System Science Ph.D. candidate at Florida International University, with my dissertation defended in June 2026 and degree expected in Fall 2026. My research integrates dragon-fruit phenology, soil and tissue nutrients, hyperspectral reflectance and production economics.

## Data and evaluation

Generated data are labeled synthetic, and the reported demonstration scores describe those datasets. Satellite scripts provide a separate route for public imagery. Original unpublished or restricted project datasets are not distributed. Real-site performance needs documented reference labels and independent validation.
