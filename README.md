## Featured Applied Projects

### [Geospatial Raster ETL & QA/QC Pipeline](projects/geospatial-raster-etl-qaqc)
A reproducible Python workflow for raster ingestion, metadata validation, mosaicking, clipping, QA/QC reporting, and analysis-ready output generation.

**Skills:** Python • Rasterio • NumPy • Pandas • raster processing • metadata • QA/QC • reproducibility

### [Spatial Validation Benchmark for Geospatial Machine Learning](projects/spatial-validation-benchmark)
A benchmark comparing random train/test splitting with spatial-block holdout to show how validation design changes the credibility of geospatial model performance.

**Skills:** GeoAI • scikit-learn • Random Forest • spatial validation • accuracy assessment • F1 • technical risk communication

### [Terrain & Hydrology Modeling Workflow](projects/terrain-hydrology-modeling)
A DEM-based workflow deriving slope, D8 flow direction, flow accumulation, and a stream-network proxy for environmental analysis.

**Skills:** terrain analysis • hydrology • DEM processing • environmental modeling • Python • QA/QC
